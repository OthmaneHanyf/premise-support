# Premise support

Premise is an app for Jira that records the assumptions behind a work item, facts to check and decisions to make, and holds the work until they are settled.

- [Support](SUPPORT.md): how to get help. To ask a question or report a problem, open an issue in this repository.
- [Privacy policy](PRIVACY.md): what Premise stores, where, and how it is deleted.

This repository holds the app's public pages only.
